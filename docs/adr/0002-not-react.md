# Target the TALL / Craft / Laravel ecosystem, not React

Dropblocs deliberately does not ship React components and does not compete with shadcn-style React registries. The customer is a freelancer or agency building CMS-driven sites with Craft CMS or Laravel, and later WordPress. The React block space is crowded and well-served; the CMS template space has almost no motion-first, agent-readable block libraries. The shadcn registry format is borrowed as prior art for distribution, not as a target.
